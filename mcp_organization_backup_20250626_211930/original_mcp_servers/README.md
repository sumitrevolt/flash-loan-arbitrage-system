# MCP Servers Directory

This directory contains the optimized set of 21 local MCP servers and 10 AI agents, along with orchestration and management scripts.

## Canonical Orchestration Scripts

- **unified_mcp_orchestration_manager.py**: Main orchestrator for MCP servers.
- **unified_mcp_integration_manager.py**: Integrates MCP servers with other system components.
- **unified_mcp_coordinator.py**: Coordinates MCP server operations.
- **intelligent_mcp_organizer.py** (in scripts/): Used for intelligent organization and cleanup.
- **mcp_server_entrypoint.sh**: Entrypoint for MCP server containers.
- **unified_mcp_organizer.ps1**: PowerShell organizer for MCP servers.
- **Start-Simple-MCP.ps1**: PowerShell launcher for simple MCP setup.
