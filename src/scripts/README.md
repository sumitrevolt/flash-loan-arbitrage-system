# src/scripts Directory

This directory contains JavaScript scripts for MCP-powered contract setup, deployment, and verification.

## Canonical Scripts

- **mcp-setup.js**: Main MCP-powered setup for contract configuration (intelligent token/DEX setup, health checks, reporting).
- **setup.js**: General contract setup (ownership, health, token/DEX config, approvals, Aave integration).
- **ai-deploy.js**: AI-powered contract deployment and post-deployment analysis.
- **deploy.js**: Standard contract deployment script.
- **verify.js**: Contract verification script for PolygonScan.

## Usage

Run with Hardhat or Node as described in each script. See script comments for details and usage examples.
