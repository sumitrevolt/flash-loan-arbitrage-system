# Scripts Directory

This directory contains Python, PowerShell, and Bash scripts for organizing, maintaining, and launching the MCP system, Docker environments, and ABI files.

## Canonical Scripts

- **intelligent_mcp_organizer.py**: Main Python script for analyzing, ranking, and organizing MCP servers and AI agents. Preserves useful functions before cleanup.
- **smart_mcp_organizer.py**: Alternate MCP server/agent organizer (use `intelligent_mcp_organizer.py` as canonical).
- **fix_docker_startup.ps1**: Utility to fix Docker startup issues.
- **install.sh**: General project installer and environment setup.
- **launch_arbitrage_system.ps1 / .sh**: Launches the arbitrage system in PowerShell or Bash.
- **start_arbitrage_system.ps1**: Starts the arbitrage system (PowerShell).
- **check_system_status.ps1**: Checks the system status.

## Usage

Run scripts as needed for MCP organization, Docker fixes, or system launches. See each script's header for details.
